Final Inspection Bottleneck Copilot v0.2
GitHub: https://github.com/GTdbZ/final-inspection-bottleneck-copilot

這是一個使用 100% synthetic data 的製造資料分析作品集。
我用 Python / pandas 將 lot-level inspection data 轉成 station / shift summary，重新計算 weighted defect rate，並輸出 bottleneck proxy、缺陷類型排名與圖表。
專案刻意維持 generic manufacturing 定位，不綁定特定公司或製程；重點是展示我如何把製造現場問題轉成可重現、可驗證的資料分析 workflow。
